# Built by Compo website

The website for **Built by Compo**, live at https://builtbycompo.co.uk.

Right now it's a one-page "under construction" holding page. The full site comes next.

## How it works

- Plain HTML files, hosted free on GitHub Pages straight from the `main` branch.
- `CNAME` tells GitHub Pages the address is builtbycompo.co.uk. The domain's DNS is in Cloudflare.
- Fonts are open-source and self-hosted in `fonts/`, so there's no Google Fonts or cookies: Bricolage Grotesque for headings and Instrument Sans for text. Licences are next to them.

## Files

| File | What it is |
|---|---|
| `index.html` | The page |
| `404.html` | Shown for any address that doesn't exist yet |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab and phone home-screen icons |
| `img/og.jpg` | The preview image shown when the link is shared on WhatsApp, LinkedIn etc. |
| `brand/` | Logo files: `logo.svg`, `logo-white.svg` (for dark backgrounds), `logo-mark.svg`, `logo-mark-on-blue.svg` |
| `robots.txt`, `sitemap.xml` | For Google |
