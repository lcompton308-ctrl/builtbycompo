# Built by Compo website

Live at https://builtbycompo.co.uk. Hosted free on GitHub Pages from the `main` branch.

Right now it's a temporary "Website under construction" holding page. Colours and fonts are placeholders and will change.

- `index.html`: the page
- `404.html`: sends any unknown address back to the home page
- `CNAME`: tells GitHub Pages the address is builtbycompo.co.uk (DNS is in Cloudflare)
- `fonts/`: free stand-ins, self-hosted (no Google Fonts, no cookies)
  - TeX Gyre Adventor Bold, standing in for ITC Avant Garde Gothic (GUST Font Licence)
  - Fraunces Black, soft setting, standing in for Cooper BT (SIL Open Font Licence)
